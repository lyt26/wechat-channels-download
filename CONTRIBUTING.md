# Contributing

Thanks for helping make WeChat Channels Downloader easier for beginners.

## Ways to help (great for stars & quality)

1. **Star** the repo and share with friends who need 视频号 downloads
2. Open issues with failing share links (redact private info)
3. Improve docs (typos, clearer beginner steps, more languages)
4. PRs for GUI, batch download, or better error messages

## Dev basics

```bash
python scripts/download_sph.py "https://weixin.qq.com/sph/XXXX" -o ./downloads
```

Keep the script **stdlib-only** unless there is a strong reason to add deps.

## Code of use

Personal backup / authorized assets only. No abuse, no copyright infringement guidance.
